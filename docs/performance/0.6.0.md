# Stageviz 0.6.0 performance reference

## Windows reference A

Measured on 2026-11-22 with a Release working-tree build based on
`b0fa02d`. The companion JSON records
the exact binary and benchmark checksums. This is an initial reference for
that build.

The machine has an Intel Core i7-13650HX with 14 cores and 20 threads, 32 GiB
of RAM, and Windows 11 build 26300.9974. Both viewers used the Intel integrated
GPU with driver 32.0.101.7026, OpenUSD 25.11, and Qt
6.10.1.

The [viewer swap benchmark](../../CTest/benchmark/README.md#stageviz-and-usdview-viewport-swaps)
used 1,024 generated cubes and one sphere. Each of three serial runs
measured 90 frames per workload at 890 × 750 pixels.
Table values are the medians of each run's statistic.

| Workload | Input to swap median | Input to swap p95 | Swap interval median | Swap interval p95 |
| --- | ---: | ---: | ---: | ---: |
| usdview StageView orbit | 8.91 ms | 13.33 ms | 9.03 ms | 13.29 ms |
| Stageviz orbit | 12.33 ms | 13.05 ms | 12.40 ms | 13.16 ms |
| Stageviz orbit with selection | 25.68 ms | 26.54 ms | 25.75 ms | 26.62 ms |

[Windows reference A Release data](0.6.0-windows-a-release.json) includes
the hardware and software profile, fixture hash, paint-to-swap timing, and
selected Stageviz phase timings from separate traced runs.
